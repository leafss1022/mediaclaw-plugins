# 企业微信通知与控制台

1. 创建企业微信自建应用，填写企业 ID、应用 ID、Secret 和通讯录管理员 UserID。
2. 保存并启用插件，点击「保存并发送测试消息」。检查应用可见范围及可信 IP。
3. 需要远程操作时，配置公网访问地址、回调 Token 和 EncodingAESKey，把生成的
   接收消息 URL 填入企微后台。启用「远程控制」，保存后自动同步菜单。
4. 影视搜索和订阅还需绑定 `UserID=MediaClaw成员登录名`，每行一项。

## 菜单与选片

- 控制中心：功能首页、系统状态、任务中心、媒体库。
- 影视服务：搜索影视、我的订阅。
- 更多功能：通知状态、使用帮助。

「搜索 沙丘」和「订阅 沙丘」均返回候选图文，显示图片、片名、年份、评分、类型和简介，
随后显示对应的订阅按钮。我的订阅及订阅成功回执也采用图文。
点击指定影片的订阅按钮后执行；按钮仅当前用户和绑定成员可用，2 分钟后失效，
使用一次即失效，不会自动订阅第一个搜索结果。

系统概览为只读摘要，不返回密钥、完整任务输入或媒体文件路径。订阅继续使用宿主的
成员权限和原有订阅服务。参考 DaquanClaw 的交互，但菜单仅接入本版实际支持的能力，
未移植其重启服务、网盘控制、会员管理与站点管理操作。

## 通知与诊断

支持订阅/入库、播放事件及自定义事件匹配；取消所有事件即不推送。
关键词过滤仅作用于事件通知，不阻止指令回复。消息只提取媒体名称等展示字段，
不会发送原始 JSON。通知采用企业微信原生 `news` 大图文：横幅图片、状态标题与多行明细。
图片优先使用背景图，其次海报，最后使用 MediaClaw 的默认封面。

- 入库：真实季集范围、评分、类型、媒体库、质量、相关在位文件数量与体积、简介。
  文件数和体积为本次涉及单元的当前库存，不宣称是本次新增量；缺少数据时不编造。
- 下载：站点标识、资源名称、质量、体积、发布时间、做种、促销、H&R、资源描述。
- 播放：图片、状态、季集、播放进度；保持现有事件开关，未订阅事件不会自动启用。
- 免费到期时间、站点标签、站内信尚无完整事件来源，本轮没有新增站内信抓取或管理菜单。

本地元数据通过受限只读门面补全，不为发送通知重新刮削 TMDB 或探测媒体。
图文标题最多 128 UTF-8 字节、摘要最多 512 UTF-8 字节，长简介会截断并加省略号。
打开图文进入 MediaClaw 媒体库；未配置外部访问地址时，有 TMDB 标识的影片打开 TMDB 详情。
原生消息的字号和圆角由企业微信客户端控制，服务端提供图片与内容。

请配置手机及企业微信可访问的外部访问地址，用于本地图片、默认封面和媒体库链接；
仅填写内网地址不能保证图片在外网显示。没有可用图片或详情链接时会降级为文字，
插件状态页显示「图文显示提示」。没有注入登录 Token 到图片或详情链接。
文字兜底按 UTF-8 字节分段。

插件数据页显示连接、回调、菜单状态及最近 30 条记录，最多保留 100 条收发/操作记录。
清理记录不会清空回调去重状态。Token 自动缓存与合并刷新；临时网络、限流错误最多
尝试 3 次，永久性配置错误直接提示。部分接收人无效会明确报错。

API 转发地址留空直连官方接口；填写时必须使用自己信任的 HTTPS 服务。
凭据会经过该服务，宿主只开放插件声明并由管理员配置的转发地址，不放开全网访问。
手动 Access Token 会优先使用且不会自动续期；改回 Secret 模式请显式勾选清空手动 Token。
密钥输入框留空表示保留；启用中的插件不能清掉仍必需的密钥，需要同时提供替代凭据或先停用。

## 可靠性与兼容

验签、解密、白名单及时间窗口校验后，消息写入插件持久收件箱再应答。
后台串行处理；MsgId（事件用稳定字段组合）在 10 分钟内去重，回调时间容差 5 分钟。
收件箱最多 100 条，过载返回失败让平台稍后重投。停用会取消后台协程并保留待处理消息，
下次启用恢复；过期指令不执行。待确认选片不跨重启保存，需要重新搜索。

1.1.0 需要配套的 MediaClaw 主程序补丁（计划随 0.29.1 发布）。当前改动尚未发布。
新增主程序能力包括受限只读控制台、配置变更通知、显式清空密钥、命名插件操作，
以及原子保存插件数据。没有新增数据库表和运行时依赖。
