# 内置媒体库封面生成

为 **MediaClaw 内置媒体库**生成封面，不需要填写外部媒体服务器、地址或 API Key。

1. 先在内置媒体库入库并刮削，确保作品已有本地海报。
2. 启用插件，配置中勾选目标媒体库；不勾选表示全部。
3. 选择「标题与单图 / 斜切背景 / 多图海报墙 / 氛围标题」。
4. 点击「保存并生成」，封面会直接应用到对应媒体库。插件数据页显示结果与跳过、失败原因。

默认每天 06:00 更新；周期和暂停在宿主「计划任务」中管理。
默认保留手动上传的封面，勾选「替换手动上传的封面」后才替换。生成失败保留原图。
清理插件记录不删除库封面；需要恢复系统拼贴时，在媒体库编辑页使用「恢复自动拼贴」。

输出为 1260×600 的 JPEG。文件由宿主管理，默认保存在
`data/uploads/library-covers/{库id}.generated.jpg`；插件不读取媒体路径或直接访问数据库。

0.1.2 需要 MediaClaw 0.29.1 或更新版本；旧版主程序缺少生成接口时会明确提示升级。
旧版展示但未接入的外部服务器、动画、字体路径等选项不再展示；旧配置仍保留在数据库，
本版仅使用目标库、静态风格、手动封面替换开关和记录数量。
